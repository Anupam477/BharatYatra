🌐 **Live Website:** [https://bharat-yatra-iota.vercel.app/](https://bharat-yatra-iota.vercel.app/)

---

## ⚡ Key Highlights & Features

- **🤖 AI Smart Itinerary Planner:** Generates custom day-by-day itineraries with verified local spots, timing schedules, and estimated budgets.
- **🗺️ Interactive Map of Bharat:** SVG cartographic radar with live climate inspection, travel season scores, and 1-click teleportation.
- **👁️ 360° Panoramic Immersion Portal:** Interactive drag-to-pan vistas of the Taj Mahal, Pangong Tso, and Munnar valleys with architectural trivia.
- **💰 Travel Budget & Cost Engine (`/budget`):** Real-time expense calculator for backpackers, comfort explorers, and royal palace luxury tiers.
- **🛣️ Inter-City Transit Matrix (`/transit`):** Accurate highway km, drive hours, Vande Bharat train hours, and flight durations between Indian hubs.
- **💱 Global Multi-Currency Support:** Instant client-side conversion across `INR (₹)`, `USD ($)`, `EUR (€)`, and `GBP (£)`.
- **🕒 Live IST Clock & Weather Ticker:** Real-time Indian Standard Time clock with live weather conditions and Govt Tourist Helpline (`1363`).
- **🧬 Travel DNA Matcher:** 30-second personality quiz matching users with their authentic Indian travel archetype.
- **❤️ LocalStorage Wishlist:** Instant bookmarking for destinations and luxury palace stays.
- **🎵 Sounds of Bharat:** Offline Web Audio classical Raag Bhupali meditation harmonics.

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router + Turbopack)
- **Library:** React 19
- **Styling:** Vanilla CSS & Tailwind CSS v4 (Glassmorphism & Dark Mode)
- **Icons & Animation:** Lucide Icons, Framer Motion
- **Sound:** Web Audio API (zero external audio dependencies)
- **Deployment:** Vercel

## 🚀 Quick Start (Local Setup)

```bash
# 1. Clone the repository
git clone https://github.com/Anupam477/BharatYatra.git
cd BharatYatra

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.
